# 数独 · 雅集 — 美术与体验设计文档

> 定位：一款「可以玩很多年」的数独。视觉上不做花哨的卡车皮，而是给数独一个**文化容器**——
> 参考网易系国风产品（如《逆水寒》《遇见逆水寒》的文人雅趣方向），把数独的「静、序、思」
> 与宋代文人美学（宣纸、墨、青瓷、朱砂、鎏金）对齐，让「做题」变成「焚香抚琴」式的日常仪式。

## 一、设计概念：文人四雅 × 数独四时

| 概念词 | 落点 |
| --- | --- |
| 静 | 大面积留白宣纸底，无一处多余装饰；信息密度向棋盘集中 |
| 序 | 9×9 格线如界格书法：细线为格、粗线为宫，层级只用线条粗细表达 |
| 思 | 候选数笔记做成「小楷旁批」，弱灰不抢主字 |
| 功 | 星标用鎏金、错误用朱砂、作答用青瓷——**颜色只承载语义，不承担装饰** |

## 二、色彩系统（Design Tokens）

主题以 CSS 变量内置双主题，`index.wxss` 顶部即完整 token 表：

| Token | 雅纸（默认） | 玄墨（夜间） | 语义 |
| --- | --- | --- | --- |
| `--paper` | `#F7F3EA` 宣纸 | `#211D18` 玄墨 | 页面底色 |
| `--card` | `#FFFDF8` | `#2C2721` | 棋盘/卡片纸面 |
| `--ink` | `#2B2620` 浓墨 | `#EDE4D3` | 题面数字（给定数） |
| `--celadon` | `#3E7C6F` 青瓷 | `#5FA393` | 玩家作答、主按钮 |
| `--gold` | `#C9A063` 鎏金 | `#D4AF7A` | 选中格、星标、新纪录 |
| `--vermilion` | `#C3392B` 朱砂 | `#E06A5A` | 错误、冲突、危险操作 |

配色原则：
1. **7:2:1**——纸墨占七、青瓷占二、金银朱点一；任何时刻屏幕上纯色块不超过三种。
2. 所有彩色都绑定语义（作答/选中/错误），玩家扫一眼即可读盘。
3. 深色主题不是简单反色：底色压至暖黑（非纯黑），文字用米白降低眩光，彩度整体上调一档补偿对比。

## 三、字与排版

- 数字使用系统字体 + `font-variant-numeric: tabular-nums`，保证 1/7 等宽数字对齐如铅字排版。
- 题面 42rpx / 作答 600 字重 / 笔记 17rpx 三级字阶，主次一眼可分。
- 标题加 `letter-spacing: 2~6rpx`，做出「题签」的从容感。

## 四、棋盘（视觉主角）

- 界格线：宫界 3rpx 浓墨、格线 1rpx 淡墨，外框 4rpx——完全对应书法界格与围棋盘的线级语言。
- 选中态：鎏金内描边 + 淡金底（不用高饱和填充，避免刺眼）。
- 同数高亮：淡金底；行列宫（peer）：青瓷淡染 12% 透明度，可在设置关闭。
- 冲突/错误：朱砂字 + 朱砂淡底 + 0.4s 抖动，反馈明确但不惊吓。
- 暂停/结算时盘面以宣纸色整体覆遮（防偷看 + 防原生层误触），配「休息一下 / 大功告成」字样。

## 五、动效原则（克制的三处动效）

1. **星标 pop**：结算页三星依次弹出（0.28s 间隔，过冲曲线），配合逐星音效——成就感的核心时刻。
2. **金屑洒落**：胜利时 14 枚金/瓷/朱纸屑飘落两轮，止于「雅」，不做全屏轰炸。
3. **错误抖动**：0.4s 水平 shake + 淡红底，一次反馈即止。
其余一切状态切换只用 0.12~0.25s 的颜色/透明度过渡；没有整页转场动画，尊重数独的高频操作节奏。

## 六、声音设计

- 全部为本地合成的原创音（`game/audio/sudoku/`），零版权风险。
- 落子=木鱼式轻叩、笔记=小楷沙沙、错误=低哑磬声、**胜利=宫商角徵羽五声音阶琶音**（国风记忆点）。
- 高频音效走音频池支持重叠；不跟随系统静音键，应用内提供静音开关并持久化。

## 七、玩法与节奏（大厂保留项清单）

- **无限关卡**：种子化确定性生成——关卡 N 全世界玩家同一盘面（可做排行榜/好友比拼的基础）。
  难度随关卡爬坡：入门(≤40) → 简单(≤120) → 中等(≤260) → 困难(≤480) → 专家(≤800) → 大师，
  线索数 42→24，全部强制唯一解。
- **三心失误制**：错 3 次判负，把「试错」变成决策成本。
- **星评**：3★=零失误零提示；2★=失误≤2；1★=完成即得。记录每关最佳时间。
- **每日挑战**：按日期种子生成固定「困难」盘，连击（streak）养成日活习惯。
- **完整辅助链**：笔记 / 一键笔记（自动候选数）/ 填数自动清理同行列宫笔记 / 撤回（40 步快照）/
  擦除 / 提示×3 / 数字剩余计数（用完置灰）。
- **防偷跑计时**：切后台自动暂停并返回暂停页；弹层打开时计时冻结。
- **无障碍细节**：同数高亮 + 行列宫高亮可关（高敏用户）、震动反馈可关、全部颜色语义均同时有
  位置/粗细冗余编码（不只靠颜色区分状态）。
- **内置修改器（雅集模式）**：设置页「修改器」开关直接启停（无隐藏入口）。
  开启后修改器功能内嵌在同一设置弹框内（金色分区标题 + 开关 + 动作按钮）；
  **关闭主开关时自动复位全部作弊开关**，避免透视/时间静止等状态残留。
  功能：不判错 / 无限提示 / 透视答案（空格淡显正解）/ 时间静止 / 一键完成 / 回满爱心 / 跳关 / 时间清零。
  **诚信设计**：会话内一旦使用修改器，本局胜利只演出不计账——星标、解锁、每日连击、战绩全部不入库；
  结算页明确标注「修改器模式 · 本局战绩不计入」。排行榜/好友比较的数据因此始终可信。
