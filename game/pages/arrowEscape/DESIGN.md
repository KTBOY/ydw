# 箭头逃脱 · 美术与设计规格（QQ 农场风格）

> 依据腾讯 QQ 农场截图定稿的美术方向：明亮饱和的卡通农场、天空—绿丘—草地三层场景、
> 圆角「菜畦」棋盘、暖橙色圆形按钮 + 奶油木牌 UI。改配色/布局前先读本文档，保持风格统一。

## 1. 场景构成（Canvas 自上而下）

| 层 | 内容 | 关键色 |
| --- | --- | --- |
| 天空 | 垂直渐变 + 太阳光晕（右上）+ 3 朵白云（椭圆簇 + 底部青灰阴影） | `#7fd4f6 → #c7effc` |
| 远山 | 两层圆弧山丘（`ellipse` 半圆穹顶），后层浅、前层深 | `#b9e286` / `#9ed367` |
| 草地 | 垂直渐变，占画面约 74% | `#96d45f → #7fc74b` |
| 点缀 | 圆冠树（三圆树冠+高光）、木篱笆（地平线两侧）、花草（固定种子伪随机散布，避开棋盘） | 见 `index.js` 常量 |
| 田地 | 深土外框 + 浅土内框 + 菜畦格子 | `#9a6a38` / `#c98d4e` |

- 菜畦格子：圆角方块，双色交错（`#daa469` / `#d09a58`）+ 底部厚度边 `#8a5c2e` + 部分格子犁沟纹理 + 顶部白色受光条。
- 棋盘上方挂一块木牌「剩余 N」（仿「劳动光荣」木牌），竖向空间不足时移入棋盘内左上角。
- 静态场景整体绘制进 **OffscreenCanvas 离屏缓存**（`ensureBackground`），每帧仅 `drawImage` + 动态元素；
  低版本库不支持离屏画布时自动退化为每帧直接绘制。缓存 key = 宽高 + 行列数（关卡棋盘尺寸变化才重建）。

## 2. 箭头（糖果玩具质感）

- 形状：整体填充绘制（非描边线）——粗圆身体（宽 0.5 格）+ 圆角三角大头（半宽 0.52 格、长 0.44 格，fill+同色 stroke 得圆角）+ 尾部大圆钮。
- 明暗：按几何包围盒做垂直渐变（顶部提亮 36% → 原色 → 底部加深 24%），模拟顶光体积感，L 形弯箭头同样自然；身体/大头/尾钮共用同一渐变无缝拼合。
- 绘制顺序：金色提示光晕（径向渐变呼吸，`hintT` 1.8s）→ 落地投影（身体/大头/尾钮同步外扩下沉）→ 深描边（主体色加深 42%）→ 渐变主体 → 白色高光线 + 尾钮/大头高光点。
- 色板为农场糖果色（`levels.js` 的 `PALETTE`，12 色循环），土黄棋盘上靠深描边保证对比度（玉米黄等浅色同样依赖描边）。
- 动效：入场 easeOutBack 弹跳 + 逐个错峰（`spawn = i×35ms`，延迟期内不可点击）；滑出 ease-in 加速 + 起手回拉 + 残影拖尾；受阻阻尼摆动 + 震动/扣命；点击按压回弹缩放。

## 3. 页面 UI（WXML/WXSS）

- 顶栏：橙色圆形静音钮 + 奶油色胶囊「第 X / 100 关」+ 爱心胶囊「❤ × N」。
  页面背景 `#7fd4f6` 与画布顶部同色；底部按钮区渐变起点 `#7fc74b` 与画布底部草地同色，两处均无缝拼接。
- 底部按钮：4 个橙色圆形按钮（提示 / 重玩 / 关卡 / 记录），radial-gradient + 深色描边 + 立体投影，按下下沉 4rpx。
- 弹窗：奶油卡片（`#fffdf2` + `#f0dfae` 描边），主按钮橙色渐变、次按钮米色。
- 过关星级：剩余生命 ≥4 得 3 星、≥2 得 2 星、其余 1 星；金色星星依次弹入（`starPop`）。
- 关卡选择：5 列菜畦格子节点，未解锁灰土色 + 🔒，当前关金圈高亮，`scroll-into-view` 定位当前关；顶部显示累计星星。

## 4. 数据与存储键

| 键 | 内容 |
| --- | --- |
| `arrowEscapeLevel` | 已解锁的最大关卡下标（0 基） |
| `arrowEscapeStars` | 每关最高星级 map：`{ [levelIdx]: 1~3 }` |
| `arrowEscapeScores` | 游玩记录（最多 10 条） |
| `arrowEscapeMuted` | 静音开关 |

## 5. 已知机制结论（勿破坏）

- 移除箭头只会减少障碍，可解性单调不变 → **任何残局必有解**，不会死局；提示恒可用。
- 生命耗尽是唯一失败条件（连续误点受阻箭头 5 次）。
- 弹窗显示时 canvas 必须加 `hidden`（原生组件同层渲染兜底），关闭后主动重绘——关卡/记录弹窗同理。
